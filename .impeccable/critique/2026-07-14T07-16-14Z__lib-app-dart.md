# Anti-Patterns Verdict

**LLM assessment: PASS with three demerits.** The site does not read as AI-generated: real device frames with the actual product, real client logos, calm blue/purple system, no gradient text, no glassmorphism, no eyebrow scaffolding. Demerits: (1) animated blur-blob "mesh" decorations survive on /contact-us and /free-demo (removed everywhere else); (2) the dark-purple 404 gradient is tonally alien to the calm light site (user-requested, so noted, not condemned); (3) About-page stock photos, one of which (`ai_chatbot_interface.webp`) is a recognisable ChatGPT app screenshot used as the CU Chat features centerpiece.

**Deterministic scan:** clean on Dart source (likely unsupported input); on rendered HTML: 4 findings, 2 "marketing-buzzword" (false positives, matched "leading" in social-proof lines) and 2 "numbered-section-markers" (home process 01-04, CU Chat steps 01-03; both are genuine sequences, so acceptable per the ban's own carve-out).

**Visual overlays:** not injected; evidence was gathered via scripted per-page checks in the browser instead.

# Overall Impression

A credible, calm, product-led marketing site that passes the slop test and looks premium, but the conversion spine is broken: the contact form silently loses every lead, the booking modal is a blank white void at the highest-stakes moment, the stats animate through false numbers, and the strongest trust asset (six named CEO testimonials, already coded) is unmounted. The visual layer is ahead of the functional layer.

# What's Working

1. **Hero device frames with the real product** (FSCS marks, real member-app UI) — the best trust signal a risk-averse CU buyer could ask for, front-loaded.
2. **Real client logos** (13+ genuine UK credit unions) on a brand-tinted band — social proof most competitors fake.
3. **Disciplined brand theme** — `web/theme.css` as single source of truth, self-hosted Outfit with unicode ranges and preload, reduced-motion honored, coherent radius/colour tokens.

# Priority Issues

- **[P0] Contact form goes nowhere.** `contact_us.dart` form has no action/handler; submission reloads the page and silently loses the lead. Fix: wire to a form backend (CF Pages function / Formspree), add `required`, success and error states. → `$impeccable harden`
- **[P0] ChatGPT screenshot sold as their chatbot.** `images/ai_chatbot_interface.webp` on /about and as CU Chat features centerpiece; "Get Plus / Create image" legible. A prospect's IT advisor will recognise it. Fix: replace with a real CU Chat screenshot in a branded frame. → content/asset swap
- **[P1] Contact page fails WCAG AA contrast.** #259CE2 on white = 3.03:1 for eyebrow, links, and the white-on-blue submit button label. Fix: darken to a ~4.5:1 blue (e.g. #1977B0-range) for text/small elements on white. → `$impeccable polish`
- **[P1] Animated stats flash false values; testimonials unmounted.** Count-up shows "52% member satisfaction" to skimmers; six named CEO quotes in `testimonials_section.dart` are imported nowhere. Fix: start count-up at ~90% of target; mount TestimonialsSection on home. → `$impeccable polish`
- **[P1] Booking modal is an anxiety void.** Blank white sheet + invisible X while Calendly loads. Fix: heading, loading skeleton, visible close, fallback phone/email line. → `$impeccable harden`
- **[P2] Dead link + inconsistent phone numbers.** /case-studies 404s from the contact page; banner numbers differ from contact-page numbers. Reconcile to one canonical set; remove or build case studies.
- **[P2] Residual mesh blobs + dead `middle-0` classes** on /contact-us and /free-demo — the one remaining AI-template tell. → `$impeccable quieter`
- **[P2] A11y/perf hygiene.** Missing h1 on /app-features; daisyUI footer-title h6 jumps site-wide; unlabeled hamburger; lazy-load below-fold images on /about and /cu-chat; downscale 4500px logos. → `$impeccable polish` / `$impeccable optimize`
